# Specs

This directory holds the design specifications for baud-forge.

## Naming

Use `NNNN-kebab-title.md`. Increase the number by one for each new spec.

## Content

Each spec has these sections:

1. Problem: what the user cannot do today.
2. Scope: what the spec covers, and what it does not cover.
3. Behavior: what the product does, step by step.
4. Data: structs, wire formats and files, if any.
5. Test: how a reviewer confirms the behavior.

Write the spec before the code. Update the spec when the behavior changes.
